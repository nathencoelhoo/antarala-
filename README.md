# ANTARĀLA

A concept website for a minimalist luxury clothing label based in Goa, India. Wearable architecture for the Indian climate, made to measure and sold by appointment.

**This is a concept project.** The garments do not exist yet. All images are AI-generated design renderings, and the legal pages are draft templates, not legal advice.

## Pages
- `index.html`: home (capsule, The Spine, atelier, appointment, travelling fittings)
- `about.html`: the name, the founder, the studio, how we work
- `pieces/`: five product pages (Chhaya, Stambha, Dhara, Mandapa, Adhar)
- `cart.html`, `checkout.html`: bag and order request (sent by email, no payments)
- `privacy.html`, `terms.html`, `shipping-returns.html`, `legal-notices.html`: draft legal pages

## Built with
Plain HTML, CSS and JavaScript. No build step. Type is Barlow Condensed.

## Run locally
`npx serve .`

## Deploy
Push to GitHub and import the repo in Vercel. No settings needed.

## Before a real launch
- Replace every `[BRACKET]` placeholder (legal details, studio address, founder name)
- Set the real email in `js/main.js`
- Replace renderings with real photographs
- Have an Indian advocate review the legal pages
- Check the ANTARĀLA trade mark
